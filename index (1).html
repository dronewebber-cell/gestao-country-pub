Configurações e segurança

Este é um protótipo para avaliação. Os dados ficam no armazenamento local deste navegador, sem login, backup na nuvem ou sincronização entre aparelhos. Não utilize dados reais de clientes ou cobranças de produção nesta versão.

Próximas integrações

Para cobranças automáticas reais: banco de dados online, login com permissões, agendador, integração oficial com WhatsApp ou outro canal autorizado, consentimento e registro dos envios.
